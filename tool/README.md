# Ran_Type_LCD 用ツール

## audio_to_carray.py — 音声ファイルを C 配列に変換

このソフトの BGM 用に、WAV を **int16_t PCM・16000 Hz** の C 配列に変換します。  
`src/sound/sound.cpp` の `BEACH_BGM` / `BONFIRE_BGM` / `RAIN_BGM` と同じ形式で出力します。

### 必要なもの

- Python 3.6+
- 標準ライブラリのみ（`wave`）で動作

### 使い方

```bash
# 基本（出力は標準出力）
python tool/audio_to_carray.py input.wav -n MY_BGM

# ファイルに出力し、サンプルレートを 16000 Hz に変換
python tool/audio_to_carray.py input.wav -o my_bgm.c -n MY_BGM -r 16000

# BGM 用に先頭 64 サンプルだけ使う（ループ用）
python tool/audio_to_carray.py input.wav -o my_bgm.c -n MY_BGM -r 16000 -m 64
```

### オプション

| オプション | 説明 |
|-----------|------|
| `input` | 入力 WAV（16bit、モノまたはステレオ） |
| `-o`, `--output` | 出力 .c ファイル（省略時は標準出力） |
| `-n`, `--name` | C 配列の変数名（既定: AUDIO_SAMPLES） |
| `-r`, `--rate` | 出力サンプルレート [Hz]（既定: 16000） |
| `-m`, `--max-samples` | 最大サンプル数。0 で全サンプル（既定: 0） |
| `--values-per-line` | 配列の 1 行あたりの値の数（既定: 8） |

### 出力形式

```c
/* Generated by tool/audio_to_carray.py */
/* Source: input.wav, rate=16000, samples=64 */

static const int16_t MY_BGM[64] = {
    0, 200, 400, 300, ...
};
```

生成した配列を `sound.cpp` で使う場合は、`get_bgm_data()` に新しい BGM を追加するか、既存の `BEACH_BGM` 等を差し替えてください。
